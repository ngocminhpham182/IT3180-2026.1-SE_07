## Các xử lý tích hợp đáng chú ý

- Giữ `/api/v1` ở HTTP client, sửa Vite dev proxy để bỏ prefix trước khi chuyển tới Spring Boot. Đã đọc controller ở nhánh hiện tại và nhánh backend bổ sung: mapping không có `/api/v1`. Có unit test proxy giữ nguyên query `dryRun=true`.
- Dùng envelope `data`, ApiError `code/fields/details`, hỗ trợ lỗi 400/409/422 theo contract; không gọi DB từ frontend.
- Không tự gửi lại POST generate khi timeout/mất mạng/phản hồi không xác định: gọi GET chi tiết kỳ. Nếu GET cũng lỗi thì chặn lập lại và hiện nút kiểm tra trạng thái. Nếu đã lập thì hiển thị công nợ. Nếu chưa lập thì người dùng phải xem trước/xác nhận lại.
- Khi POST generate thành công nhưng GET tổng hợp lỗi, vẫn giữ trạng thái đã lập để tránh gửi trùng.
- Lịch sử biến động và số tiền kỳ lấy từ API; không giả lập kết quả thành công khi server lỗi.
- Sau ghi biến động, cập nhật hồ sơ cư dân và tải lại lịch sử; trang hộ tải lại số lượng từ API khi điều hướng trở về.
- Ngày validation biến động theo `Asia/Ho_Chi_Minh`; khai sinh là `entryType=BIRTH` ở luồng thêm nhân khẩu, không gửi BIRTH tới `/movements`.
- Contract v5 chỉ giới hạn đơn giá `(0, 1.000.000.000]`, không ép 2.500–16.500. FE theo quy tắc này.

## Kiểm thử và cách chạy

Các test mới nằm ở `tests/supplement.test.mjs`, `tests/proxy.test.mjs`, `tests/supplement-flows.test.jsx` và `tests/browser/supplement.spec.js`. Giữ và chạy lại test cũ.

- `npm run check`: **106 test** (24 Node + 82 Vitest), gồm validation, payload, route permissions, lịch sử/chủ hộ thay thế, stale search, voluntary fee, khóa inUse, tính thử/thiếu diện tích, create period, dry-run/generate, duplicate, close period và timeout reconciliation.
- `npm run build`: build production bằng Vite.
- `npm run test:browser`: **6 lượt** trên desktop 1440×1000 và mobile 390×844; có luồng tìm kiếm → cư dân → biến động, tính thử, xem trước → lập kỳ, kiểm tra cuộn ngang và lỗi JS.
- Browser dùng HTTP fixture, không phải test Spring Boot/DB. Ảnh được lưu trong `test-results/` (gitignored), gồm `fee-preview.png`, `billing-preview.png`, `billing-result.png` theo từng viewport.

Chạy làm việc: `npm run dev`, mở `http://localhost:5173`; cấu hình `API_PROXY_TARGET` tới backend đúng contract. Không cần thêm dependency. `npm run preview` không có dev proxy; production cần reverse proxy bỏ `/api/v1` và fallback các route frontend về `index.html`.
